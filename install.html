安裝天主教講道筆記 App

把講道筆記放到手機主畫面，隨時閱讀聖經金句與講道，並下載備份。

直接開啟首頁

若未出現安裝提示，請依照下方說明操作。

手機安裝方式

  • Android：用 Chrome 開啟本頁，點「安裝 App」；也可在右上角「⋮」選「安裝應用程式」或「加到主畫面」。
  • iPhone／iPad：用 Safari 開啟本頁，點「分享」→「加入主畫面」。
  • 電腦：用 Chrome 或 Edge 開啟，點安裝按鈕或網址列的安裝圖示。

若從 LINE 等 App 開啟，請複製下方連結，貼到 Chrome 或 Safari。若已安裝，瀏覽器可能不再提供安裝選項，可直接使用原有圖示。

分享安裝連結

這是加入主畫面的網站 App。首次請保持連線，等「已可離線閱讀」出現後，就能離線使用；管理後台及內容更新需要網路。
